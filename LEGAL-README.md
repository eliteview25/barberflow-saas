# Páginas legais

Foram incluídas páginas iniciais de Termos de Uso, Privacidade, LGPD e Cancelamento, além do registro de aceite de Termos/Privacidade no cadastro.

Antes do lançamento público, revise os textos com os dados reais do responsável pelo BarberFlow (razão social/nome empresarial, CNPJ quando aplicável, endereço e canal oficial de privacidade) e, se necessário, com assessoria jurídica. O software não inventa esses dados.
