# Páginas legais e LGPD — EliteFlow 4.5.5

A versão 4.5.5 inclui: Termos, Privacidade, LGPD, Cancelamento, Cookies/Armazenamento Local, DPA e Terceiros/Integrações, além de documentos internos de incidentes, retenção e mapa de dados.

## Antes do lançamento comercial
Configure no ambiente os dados reais do responsável pelo EliteFlow:
- `LEGAL_ENTITY_NAME`
- `LEGAL_CNPJ` (ou identificação aplicável)
- `LEGAL_ADDRESS`
- `PRIVACY_EMAIL`
- `PRIVACY_WHATSAPP` (opcional)
- `DPO_NAME` (quando houver encarregado designado)

O software não inventa razão social, CNPJ, endereço ou encarregado.

Esta revisão é uma base jurídica-técnica e não substitui assessoria jurídica para validar a entidade contratante, enquadramento no CDC, bases legais, contratos com fornecedores, transferências internacionais e operação real.
