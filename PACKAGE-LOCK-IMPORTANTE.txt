BARBERFLOW SEGURANCA V2 — PACKAGE-LOCK

Este pacote não inclui um package-lock.json gerado offline.
Ao aplicar a V2 sobre o seu repositório real:

1) cd backend
2) npm install
3) npm audit --omit=dev --audit-level=high
4) npm test
5) npm run audit:security
6) commit package.json + package-lock.json juntos

Motivo: Multer foi removido da aplicação V2. O npm install atualiza corretamente o lockfile real e remove a dependência/transitivos que não são mais necessários.
Depois disso, mantenha o Build Command do Render como: npm ci
