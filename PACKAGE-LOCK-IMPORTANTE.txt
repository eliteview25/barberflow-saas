ELITEFLOW 4.3.0 — PACKAGE-LOCK

O lockfile válido está em backend/package-lock.json e acompanha o package.json da aplicação.
Não gere nem mantenha um package-lock.json vazio na raiz do projeto.

Validação recomendada:

1) cd backend
2) npm ci
3) npm audit --omit=dev --audit-level=high
4) npm run qa

Mantenha package.json e package-lock.json versionados juntos. No Render, use backend como Root Directory e npm ci como Build Command.
