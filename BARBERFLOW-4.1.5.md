# BarberFlow 4.1.5

Revisão dos acessos Gerente, Recepção, Barbeiro e Supermaster.

- Mantidos os menus, indicadores e limites de API específicos de cada perfil.
- Atalhos mobile corrigidos: Recepção não vê Financeiro/WhatsApp e Barbeiro não recebe acesso a Clientes.
- Resumo mobile e resposta do dashboard ocultam dados financeiros fora dos papéis autorizados; o Barbeiro mantém apenas sua comissão.
- Perfil autenticado identificado no `body` para garantir consistência visual em todas as páginas.
- Cards internos, filtros, suporte, gateways e segurança do Supermaster migrados para o visual carvão e âmbar.
- Largura do painel Supermaster corrigida no desktop e tablet.
- Drawer e botão **Sair** do Supermaster garantidos no mobile.
- Testes automatizados adicionados para visual, navegação e regras de acesso.
